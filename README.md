# Odoo Garden

Module Odoo pour la gestion du maraîchage : fermes, sites, jardins, planches, parcelles, catalogue de cultures, actions, traçabilité, post-process, pertes, rétro-planning, statistiques.

## Fonctionnalités principales
- Gestion hiérarchique : Ferme > Site > Jardin > Planche > Parcelle
- Catalogue de cultures (espèces, modes de culture, durée, etc.)
- Saisie des actions (semis, plantation, arrosage, etc.)
- Traçabilité de la graine au client
- Gestion du post-process (lavage, stockage)
- Gestion des pertes
- Rétro-planning basé sur la durée prévisionnelle
- Statistiques (rendement, taux de perte, etc.)

## Installation
1. Copier le module dans le dossier `addons` d'Odoo
2. Mettre à jour la liste des modules
3. Installer depuis l'interface Odoo
