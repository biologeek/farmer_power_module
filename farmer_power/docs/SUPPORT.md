# Farmer Power — Support

Farmer Power est un module Odoo 19 de gestion de maraîchage (`farmer_power`). Cette page décrit ce que vous pouvez
attendre du support et comment nous joindre.

## Ce que le support vous apporte

- **Efficacité** : on saisit le travail une seule fois, là où il se fait (« Ma journée », chronomètre, planification
  en série). Les coûts, les récoltes et les ventes viennent des données Stock, Employés et Comptabilité d'Odoo, sans
  double saisie.
- **Gain de temps** : le plan de culture génère les opérations prévues et les besoins en semences ; les registres
  (phytosanitaire, fertilisation, export bio) sont produits à partir de ce qui est déjà saisi.
- **Écoute des retours** : les demandes des utilisateurs orientent la feuille de route. Chaque message est lu et reçoit
  une réponse ; les demandes les plus utiles entrent dans les versions suivantes et figurent dans les notes de version.

## Nous contacter

- Adresse de contact : `odoo@biologeek.info`
- Site et page de support : `https://odoo.biologeek.info`

## Pour un signalement efficace

1. Version d'Odoo et version du module (visible dans Applications).
2. Ce que vous attendiez, et ce qui s'est passé (message d'erreur exact si possible).
3. Les étapes pour reproduire le problème, avec une capture d'écran.
4. Pour une demande d'évolution : le besoin concret sur votre exploitation (ce que vous voulez faire, pas seulement la
   fonction souhaitée).

## Engagements

- Les anomalies sont corrigées en priorité ; les évolutions sont discutées et priorisées avec les utilisateurs
  concernés.
- Les délais de réponse et le niveau de service seront précisés avec l'offre commerciale (**à définir**).
