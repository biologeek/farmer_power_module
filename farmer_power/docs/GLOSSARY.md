# Glossary of the business terms

Reference for the source strings (English) and for the translations in `i18n/`. The French column holds the
vocabulary the module used before phase 7 (kept as `i18n/fr.po`). The other columns were produced by machine
translation and **must be reviewed by native speakers**, in particular the agricultural terms.

Source-string rules: Title Case for field labels, buttons and menus; American spelling (labor, fertilizer);
"Block" is the English term for the French "îlot" (a group of beds watered by the same irrigation sector).
